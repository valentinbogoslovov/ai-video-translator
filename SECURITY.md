# Security Policy

## Supported Versions
Only the latest release on the `main` branch receives security updates.

## Reporting a Vulnerability
Please do not open public issues for security problems.
Report vulnerabilities privately via GitHub Security Advisories
("Security" tab → "Report a vulnerability") or by email to bogoslovov.one@gmail.com.

You can expect an initial response within 72 hours.
Confirmed issues will be fixed and disclosed in a published advisory,
with credit to the reporter unless anonymity is requested.
